# Polygon.io Data Downloader for Backtesting

A user-friendly Python GUI application to download historical stock and cryptocurrency data from Polygon.io. The script is designed to fetch intraday data for a specified ticker, date range, and interval, and save it as a CSV file containing only the 'Open' prices, perfect for backtesting trading strategies.

## Features

- **Dual Asset Support:** Download data for both Stocks and Cryptocurrencies.
- **User-Friendly GUI:** Simple interface built with Tkinter for easy operation.
- **Customizable Queries:** Specify ticker, date range, and time interval (1min, 5min, 10min, 15min, 30min, 60min).
- **Rate Limit Handling:** Automatically waits between API calls to respect Polygon.io's free tier limits (5 calls/minute).
- **Responsive Interface:** Data fetching runs in a background thread to prevent the GUI from freezing.
- **Robust Error Handling:** Provides clear feedback and allows continuing on minor API errors.
- **API Key Persistence:** Saves your valid Polygon.io API key locally for automatic reloading on subsequent uses.
- **Backtest-Ready Output:** Saves a clean CSV file with a single 'Open' price column and a timezone-aware timestamp index (PST/PDT).
- **Trade Backtesting Simulator:** Test trading strategies by simulating buy/sell orders against historical data.

## Requirements

- Python 3.6+
- A free API key from [Polygon.io](https://polygon.io/dashboard)

## Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/YOUR_USERNAME/polygon-data-downloader.git
    cd polygon-data-downloader
    ```

2.  **Install the required Python libraries:**
    It's highly recommended to use a virtual environment.
    ```bash
    # Create and activate a virtual environment (optional but recommended)
    python -m venv venv
    source venv/bin/activate  # On Windows, use `venv\Scripts\activate`

    # Install dependencies
    pip install -r requirements.txt
    ```

## How to Use

1.  **Run the script:**
    ```bash
    python backtest.py
    ```
2.  **Enter your Polygon.io API Key.** The key can be tested using the 'Test Key' button. A valid key will be saved locally and automatically loaded the next time you run the application.
3.  **Select the Asset Type** (Stocks or Crypto).
4.  **Enter the Ticker Symbol** (e.g., `AAPL` for stocks, `X:BTC-USD` for crypto).
5.  **Set the Start and End Dates** in `YYYY-MM-DD` format.
6.  **Choose the Time Interval.**
7.  **Click "🚀 Fetch and Save Data".**
8.  A dialog will appear to save the resulting `.csv` file.

## Trade Simulator Feature

### Overview
The Trade Simulator allows you to backtest a simple trading strategy. You provide a CSV file with historical price data (specifically 'Open' prices with PST/PDT timestamps, like those generated by the Data Downloader) and a list of buy/sell trades. The simulator then processes these trades chronologically using an 'all-in/all-out' strategy based on a specified starting capital, showing the potential performance.

### How to Use
1.  **Navigate to the 'Trade Simulator' Tab:** Select the second tab in the application window.
2.  **Load Price Data:** You have two options:
    *   **Manual Load:** Click the "Load Price Data CSV" button to select a CSV file from your computer. The CSV must have a 'timestamp' index (in PST/PDT) and an 'Open' price column.
    *   **Use Last Fetched Data:** If you have just downloaded data using the "Data Downloader" tab in the current session, you can check the "Use last fetched data (if available)" box to use it directly.
    *   The path of the active CSV will be displayed.
3.  **Enter Starting Capital:** Input your desired starting portfolio value in the "Starting Portfolio ($)" field. It defaults to $5000.
4.  **Paste Your Trade List:** In the text area labeled "Paste Trade List...", enter your trades. Each trade must be on a new line and follow this exact format: `MM/DD/YY,HH:MM,Action` (e.g., `6/14/24,9:30,Buy`).
    *   Dates are `Month/Day/Two-digit Year`.
    *   Times are `Hour:Minute` in 24-hour format, assumed to be in PST/PDT.
    *   Action must be either `Buy` or `Sell` (case-insensitive).
5.  **Run the Simulation:** Click the "🚀 Run Backtest Simulation" button.
6.  **Review Results:** The "Simulation Results" area will display:
    *   Any errors encountered during parsing or matching.
    *   A summary including Starting Capital, Final Portfolio Value, and Profit/Loss (P/L $ and %).
    *   A detailed log of each trade executed, showing the timestamp, action, price, shares transacted, and portfolio status after the trade.

#### Example Trade List:
```
6/14/24,6:30,Buy
6/14/24,9:30,Sell
```
